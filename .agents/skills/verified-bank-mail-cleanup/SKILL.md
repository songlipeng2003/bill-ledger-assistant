# 已核对银行邮件清理

## 准备

- 只使用有完整来源、最新账目证据和明确会话定位的固定清单。金额接近、日期候选、商户缺失等弱证据不自动放行。
- 邮件是会话级操作：全部消息、附件和交易都必须已覆盖。一笔已录不等于整封月账单可删；日报里退款未录也不能删。
- 如果使用配套对账报告，读取[清理合同](references/cleanup-contract.md)，本地生成清单：
  ```sh
  python .agents/skills/verified-bank-mail-cleanup/scripts/prepare_cleanup.py REPORT.json FRESH_SOURCES.json --out MANIFEST.json
  ```
  该脚本只准备清单，不操作邮箱、不发送数据、不授予删除权限。也可人工遵循相同字段生成清单，不要求对账技能已安装。

## 实际清理

1. 确认此清单在用户要求范围内，说明邮箱、封数、日期/主题、保留项以及“仅移入垃圾箱”。遵循当前工具/平台的执行前确认要求，即使之前有笼统授权也不扩大范围。
2. 按已核实来源定位打开会话，不按收件箱行号或模糊主题批删。
3. 操作前重读全部消息与来源指纹。指纹、消息组成、附件或交易有变化，跳过该会话并重新对账；不能用忽略新回复的指纹强行通过。
4. 已在垃圾箱的单独记 `already_in_trash`，不记为本次新增；不在预期位置或账号不对则停止对应操作。
5. 经确认后仅移入垃圾箱；验证结果标签/恢复入口或等效直接证据。状态不确定时先查看，禁止重复或改用永久删除。
6. 清单外状态变化只记录观察，不归因于本次、也不擅自恢复。

## 交付

本批已移入、原已在垃圾箱、跳过、失败的清单及可恢复证据。保留整月账单/问题邮件的理由。保存用户可检查的截图；不得把历史累计数量当成本次处理量。
