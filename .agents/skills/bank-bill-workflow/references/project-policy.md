# 项目规则读取

本项目配置位于项目根 `config/bill-policy.json`。配置不随单个 skill 自动传播到其他项目；复制 skill 到别处时，需要重新确认适用范围。

- 本项目时区为 Asia/Hong_Kong；每轮以当前客户端日期处理相对日期。
- 此项目用户曾确认汇丰前后2个自然日容差，保存在 `date_windows.hsbc`，其他银行默认0天。若本轮用户指定其他口径，以本轮确认规则产生新的快照，不改写历史证据。
- 货币金额按精确最小单位比较，无模糊金额容差。账户和币种不同不能因日期窗口通过而当作匹配。
- 退款分类沿用当前随手记账本的“其他收入 → 退款”。未知的其他账本需重读分类，而不是生硬创建该分类。
- 配置中的映射表初始为空。运行时从实际账户与可靠卡尾号/持卡人建立本地映射，记录证据及待确认项；不在技能中嵌入个人邮箱/真实卡号/历史消息ID。
- 自动发现技能不等于自动授权写账或删邮件。仍按当前环境实际规则，在相关副作用发生前完成必要确认。
