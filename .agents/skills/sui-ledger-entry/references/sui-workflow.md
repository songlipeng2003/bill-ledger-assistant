# 记账口径与页面经验

## 类型

- 消费：支出，原支付账户。
- 退款：按本项目既有口径为收入 → 其他收入 → 退款，存回原支付账户；不是再增加一笔消费。
- 利息/费用：费用支出，日期以原账单可靠字段为准；账单没有独立交易日时说明采用的日期口径并取得必要确认。
- 信用卡还款：来源账户转账至信用卡，不再记消费。只知还款渠道不等于已知来源银行卡，来源不清晰时不猜。
- 自有账户转账：按两个账户之间转账，不重复记成收入+支出；两边币种不同而缺少折算金额时不写入。

## 日期、分类与标识

记录实际银行交易日期。界面强制要时分但来源只有日期时，仅在清楚标注占位性质后使用00:00；保留 `time_precision: date`，不称作真实发生时间。仅提供入账日时不要静默冒充交易日。

备注使用稳定的核对标识，例如 `BILL-<稳定事件标识>`，原始商户、账单入账日与来源证据引用。标识不得每次重跑随机改变，否则不能防重。

类别优先使用现有、用户确认的分类。商户是平台/公司名称不能证明用途；不为方便批量输入而一律记餐饮。可将未知用途交付用户确认或用已认可的中性分类。

## UI恢复

按当前页面识别控件，不复用历史会话中的元素编号或固定坐标。输入框旁“+”可能是创建分类，“下拉箭头”才是选择已有分类；误开新增弹窗时取消，不创建无关分类。

保存超时后首先按唯一标识检索并重新读取字段。实际ID、日期、方向、金额、币种、账户和数量全部可验证，才算写入完成。检索不完整或一次都未读全时，不能因“未找到”直接重试。
